# v3.18.3

## 问题修复

- 重置 API 密钥额度后，清零所选周期用量并清除原重置时间，下次使用时重新确定重置日期；保留额度上限、密钥和历史费用记录
- 重置前完成但延迟落盘的费用不会重新扣入已重置周期，也不会提前开启新窗口；重置后完成的在途请求仍正常计费
- 修复出站 HTTP/2 请求重复携带 Host 信息导致部分服务拒绝请求的问题，覆盖插件来源下载；保留 HTTP 正向代理所需的原始 Host

## 管理界面

- 将周／月额度预测入口移到账号额度面板，方便与当前额度一起查看
- 错误日志增加账号当前订阅列，账号、代理关联账号和使用记录等页面统一使用“订阅”标签
- 按热点诊断维度调整列宽，改善账号信息与请求、失败、性能、费用列的空间分配

## 升级说明

- 本次不新增或修改数据库迁移
- 插件的预算重置接口与管理员操作保持一致，下次使用再计时；依赖重置后保留原截止时间的插件需调整调用逻辑，结果未知时不能盲目重复重置
- 错误日志的订阅列展示账号当前订阅，不是请求发生时的历史快照
